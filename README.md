# skills

Brandon Verzuu's personal skills, published as a Claude Code plugin marketplace.

## Install in Claude Code

```
/plugin marketplace add brand0new/skills
/plugin install writing-style@brand0new
```

To update later, run `/plugin marketplace update brand0new`, then restart Claude Code.

## What's included

- **writing-style**: the `my-writing-style` skill, for writing and editing in Brandon's voice.
